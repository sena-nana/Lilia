# LiliaCode 文档

LiliaCode 是面向代码工程的 Native Agent 协同桌面客户端，将 Lilia 产品协议与 Mutsuki AgentKit 的执行过程整理为可恢复、可追踪、可调度的本地任务状态。

本目录只保存 Markdown 文档，不生成或发布静态站点。
