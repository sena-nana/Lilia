# LiliaCode documentation

LiliaCode is a Native Agent collaboration desktop client for software engineering. It organizes Lilia product protocol and Mutsuki AgentKit execution into recoverable, traceable, and schedulable local task state.

This directory contains Markdown documentation only; no static site is built or published.
